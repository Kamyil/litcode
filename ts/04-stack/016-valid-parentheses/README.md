# 016 · Valid Parentheses

> **Difficulty:** Easy · **Topics:** stack · **Target:** O(n)

Given a string of `()[]{}`, return whether every bracket is closed by the same type in the
correct order.

## Examples

```
"()[]{}"  -> true
"(]"      -> false
"([)]"    -> false
"{[]}"    -> true
```

## Think about

- A stack is the data structure for "most recent unmatched thing". Parsers, undo, the call
  stack itself, and the SQL parser inside Postgres (a LALR parser generated by bison) all use one.
